# Projet PIV : site et Studio

- `site/` : le site public (Astro), publié sur planeur35.org.
- `studio/` : l'outil de saisie des contenus (Sanity Studio).

Les deux dossiers sont déposés dans le même dépôt GitHub, et chacun devient un projet Vercel distinct (dossier racine `site`, puis `studio`).
Suivez le guide d'installation pas à pas.
