## Claude Code

Project rules live in `AGENTS.md`, shared with GitHub Copilot and other assistants. Add new project rules there, not here.

- Ask before `git push`, before opening or merging a pull request, and before running anything in `scripts/`.
- For UI changes, check the page with `npm run dev` at `/fr` and `/en`, desktop and mobile width, before reporting the work as done. If you could not check it visually, say so.
- When you touch an area listed under "Known issues", say whether the change fixes, affects or leaves the issue.
